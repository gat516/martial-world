# Tools

What each script in `tools/` does. Read it when you need a tool and don't know its name.

- `check.sh` (luau-lsp)
- Serving a worktree (`serve.sh`): no args starts the shared servers (8767 `art/enemies/`, 8768 repo root, whichever session owns them). `tools/serve.sh <port> [dir]` serves `dir` (default: the repo root of the checkout the script lives in, so your worktree) on that loopback port, refuses a busy port and names the pid holding it, prints the base URL and logs to `tools/frag/serve-<port>.log`. In Studio set `_G.SERVE_BASE = "http://127.0.0.1:<port>/"` once: `push_src`, `anim_filmstrip`, `review_stage`, `motion_audit` and the `art/enemies` build / rig / preview / QA scripts read from it (repo-root relative; the `art/enemies` scripts add `art/enemies/` themselves) and fall back to the old ports when it is unset. The `8766` receiver (`ui_lint`, `export_check`, VFX exports) is a separate server, not affected.
- `sandbox.sh` (disposable agent Studio built from `test.project.json`: `open`/`close <name>`, `list` with ages, `prune <hours>` for leftovers, `tile`). Windows are laid out by `sandbox_windows.ps1`: a grid on the second monitor, a new one opens minimised if the rest are, and a background watcher minimises and restores them together; the user's own Studios are never touched
- `check_testbed.py` (test.project.json maps what default.project.json does)
- rbxmx export/receive (`export_rbxmx.luau` writes attributes too; `export_check.luau` + `export_check.py`: the round-trip check after every export, docs/ui/slicing.md)
- motion audit summary (`art/enemies/motion_audit.luau`, `_G.AUDIT.summary = true`): returns one table row per move (chain body / tail, stops, worst step, antic, land dip, lowest) instead of the full probe text, so a before/after is one call; docs/enemies/animating.md
- UI lint (`ui_lint.luau` dumps every GUI at four sizes, `ui_lint.py` checks clip, edge margin, slices, oversize, text, text under caps: the gate for UI work, docs/ui/slicing.md)
- UI edge-margin fixer (`ui_margin.py` + `ui_margin.luau`: margined display-sized copies and element compensation from the lint's findings)
- UI cutter (`ui_assemble.py`: Codex sheets to cuts; `--sized` display-sized copies with clear margins from `art/ui/sized/sized.json`)
- rbxm export (keeps attributes, for VFX)
- VFX library search + index (`vfx_library.luau`, `vfx_library.json`)
- animation marker reader (`anim_markers.luau`)
- enemy animation filmstrip (`anim_filmstrip.luau`: one move as 8 posed clones in a row, two captures per clip, sink and hitch markers; runs `art/enemies/motion_probe.luau`, whose metrics table it prints; see [animating](enemies/animating.md))
- asset publisher (`upload_asset.py`: animations, audio and models through Open Cloud, key in `~/.config/roblox/api_key`)
- vfxia add-on unpacker (`vfx_addons.py`)
- VFX session bootstrap (`vfx_session.luau`, generated by `build_vfx_session.py`: one paste installs every Edit-mode VFX helper)
- add-on cheat-sheet (`vfx_addons.md`, from `vfx_addons.py --summary`)
- review stage (`review_stage.luau`, `_G.reviewStage`): the live view a visual agent leaves running in its sandbox so the user watches the work (visual-gate skill, "Show the work live"). One stage at a time on a lit plate at y 1200, the editor camera parked on it, a Neon-part label over it (title and state): `model{ source }` (body or prop turning beside a 5-stud R6), `anim{ spec, move }` (the motion probe's poses looping in real time with the move's `EnemyFX` cues), `cast{ id, level, weapon? }` (the real CombatEffects path on an R6 holding its class weapon, re-cast every clip + 2 s, sounds on), `enemy{ template, cue }` (anim when `motion_specs` has the beast, else the still body with cues on the def's timings), `ui{ screen, size = "phone" }` (a copy as `StarterGui._ReviewStage` in an 844x390 or 1920x1080 stand-in, other ScreenGuis off), `camera{ view }`, `stop()`. Game lighting (`flat = true` for model_shot's). Serve the worktree (`python3 -m http.server <port>`) and set `_G.REVIEW_STAGE = { base = ... }` before loading, since `anim`/`enemy` fetch the probe from it. State lives in attributes, so `stop()` cleans up after a lost `_G`. Not for review images: captures lag the live loop, so freeze moments with `vfx_preview`/`enemy_fx_shot`
- VFX preview kit (`vfx_preview.luau`: clean scene, real CombatEffects call path, frozen captures, one-call capture sweep, `filmstrip`: six frozen moments in one labelled capture, the review image)
- enemy-effect shots and smoke test (`enemy_fx_shot.luau`: one cue sequence frozen on the real body per capture; `enemy_fx_smoke.luau`: fires every cue, reports errors, spawn counts, missing hooks)
- VFX review lints: `vfx_origin_check.luau` (live: where every layer of a template appears, its hook on the body, loose parts, missing beam attachments, offsets past the stated size), `vfx_hooks_check.py` (offline: hook and template names in `EnemyFX`/`TechniqueFX` code against the rig docs and the exported templates), `vfx_texture_audit.py` (the ten most used asset ids; hero and secondary layers that use them; exit 1 on a hero)
- review sheet (`vfx_sheet.py`: stitches screen captures into one labelled grid)
- staging/export helpers (`vfx_stage.luau`: refuses to stage over hand-edited templates; `vfx_export.sh`)
- receiver starter (`ensure_receiver.sh`)
- library contact sheets (`vfx_contact_sheet.py`)
- reference-video frame grids (`ref_frames.py`)
- template builders and specs (`vfx_blocks.luau`, `vfx_specs/`)
- structural template diff (`vfx_diff.luau`)
- world-event kit builder and preview (`worldfx_build.luau`, `worldfx_preview.luau`)
- seated-aura and root-reveal preview (`aura_preview.luau`)
- ambient sound template builder (`ambient_sounds_build.luau`)
- docs lint (`docs_lint.py`: broken links, missing paths, over-budget agents/skills/docs, text duplicated across agents and skills)
- token report (`token_report.py [--days N]`: main/subagent spend, per agent type launch size, turns, peak context, captures and per-turn tool schemas; flags runs that launched without their allowlist)
- duplicate finder
- POI tour and labels (`poi_tour.luau`, Studio copy `ServerStorage._EditorTools.PoiTour`)
- modeling checks ([modeling-checks](enemies/modeling-checks.md)): `model_shot.luau` (standard grey-box shots and capture presets, the 40-stud view, a four-view sheet), `fidelity_check.py` (silhouette IoU against a reference image, with a composite for a critic), `parts_audit.luau` (loose, kissing, hidden and z-fighting parts, part budget); Blender side `art/rig/silhouette_render.py`
- Pixal3D image-to-3D generator (`pixal3d.sh`, sources and install notes in `pixal3d/`: image to textured GLB on the Windows GPU at `D:\pixal3d`, with a RAM/VRAM preflight that refuses to run unless `--force`)
