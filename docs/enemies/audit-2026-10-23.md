# Enemy audit, 2026-10-23

Every shipped enemy measured on the same day, with a ranked work list and a ready brief per
item. The user's ask: "if there's work to be done on the bosses / monsters to make them better
anim / vfx / model wise, do it. maybe add more attacks to normal mobs that are supposed to be
difficult if need be." This file is a snapshot: when an item lands, strike it from the list
(or delete the file once all have).

## How it was measured (re-run the same way)

All in a sandbox Studio, Edit mode, at the `enemy-pass` tree (no source changes since `test`
at `d100de5`).
- **Motion:** `art/enemies/motion_audit.luau` runs `motion_probe.luau` over every attack of a
  family's def (followUps as chains, `arrive` as `next`, skids again with their skid move),
  Stagger, Death, and walk / run / circle at the def's speeds. Specs for all twelve families
  are in `art/enemies/motion_specs.luau`. Metrics are explained in [animating](animating.md).
- **Bodies:** `tools/parts_audit.luau` (with `check_rig`) on every template, budget 80 regular
  and 150 boss. No silhouette fidelity run: the user's reference row isn't in sandboxes.
- **Effects:** `tools/vfx_origin_check.luau` over every enemy group in `ReplicatedStorage.Effects`,
  `tools/vfx_hooks_check.py`, `tools/vfx_texture_audit.py`, and a runtime pass that fires every
  cue of every attack at a clone of the body and records where each spawned effect starts (a
  named body hook, the target, the telegraph, the ground under the body, or FREE).
- **Captures:** one filmstrip (Flame Raven talonDive skid, side and 3/4). No other images.

Column key for the motion tables: **peak** the fastest hero point (studs/s; budget ~600 at
contact); **hitch** heroes with a dead frame between fast ones; **worst step** the biggest
one-frame joint turn (budget ~45 deg outside deliberate snaps); **low** the lowest point against
the rest pose, with the number of frames under -0.5 (a sink or a wing through the floor);
**chain lag** frames between each link's turning peak in the release (`BLOCK` = every link +0f:
the body moves as one piece; `~` = that link barely turns); **stops dead** heroes that lose 80%
of their speed in one frame and stay still (the phase it happens in); **antic** studs the root /
first hero move back against the release in the last 30% of the windup (`none` = out of
nowhere, `~` = still at release); **land dip** how far the root dips after a dash touchdown
(`stiff` = no dip).

Calibration: the approved Spirit Wolf (the bar, "that was amazing") also shows `BLOCK` on its
quick bite and howl and paw stops in its dashes, so a `BLOCK` on a short head-only snap is not
a fault by itself. The faults below are the ones on big, slow, full-body moves, and the ones
the user has named (stops dead, moves as one block, rotates after landing, effects not from the
mouth or hand).
