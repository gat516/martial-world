# Race cosmetic briefs

The user's prompts for each race's cosmetic set, verbatim (2026-10-23), and the
shared reference sheet `docs/reference/race_cosmetics.png` (numbered panels:
1 Wolf, 2 Tiger, 3 Crane, 4 Serpent, 5 Stone Spirit, 6 Dragonblood,
7 Demonic Human, 8 Ghost). The user asked for "different variants and styles"
per race. Each set is built in Blender by a fresh `modeler`, one race at a time,
following the fox set in `art/player/cosmetics/fox/` (rig, region meshes,
recolour contract, sealed fur, sheet layout).
