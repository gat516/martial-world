# Tools

What each script in `tools/` does. Read it when you need a tool and don't know its name.

- `check.sh` (luau-lsp)
- `sandbox.sh` (disposable agent Studio built from `test.project.json`: `open`/`close <name>`, `list` with ages, `prune <hours>` for leftovers, `tile`). Windows are laid out by `sandbox_windows.ps1`: a grid on the second monitor, a new one opens minimised if the rest are, and a background watcher minimises and restores them together; the user's own Studios are never touched
- `check_testbed.py` (test.project.json maps what default.project.json does)
- rbxmx export/receive
- rbxm export (keeps attributes, for VFX)
- VFX library search + index (`vfx_library.luau`, `vfx_library.json`)
- animation marker reader (`anim_markers.luau`)
- asset publisher (`upload_asset.py`: animations, audio and models through Open Cloud, key in `~/.config/roblox/api_key`)
- vfxia add-on unpacker (`vfx_addons.py`)
- VFX session bootstrap (`vfx_session.luau`, generated by `build_vfx_session.py`: one paste installs every Edit-mode VFX helper)
- add-on cheat-sheet (`vfx_addons.md`, from `vfx_addons.py --summary`)
- VFX preview kit (`vfx_preview.luau`: clean scene, real CombatEffects call path, frozen captures, one-call capture sweep, `filmstrip`: six frozen moments in one labelled capture, the review image)
- enemy-effect shots and smoke test (`enemy_fx_shot.luau`: one cue sequence frozen on the real body per capture; `enemy_fx_smoke.luau`: fires every cue, reports errors, spawn counts, missing hooks)
- VFX review lints: `vfx_origin_check.luau` (live: where every layer of a template appears, its hook on the body, loose parts, missing beam attachments, offsets past the stated size), `vfx_hooks_check.py` (offline: hook and template names in `EnemyFX`/`TechniqueFX` code against the rig docs and the exported templates), `vfx_texture_audit.py` (the ten most used asset ids; hero and secondary layers that use them; exit 1 on a hero)
- review sheet (`vfx_sheet.py`: stitches screen captures into one labelled grid)
- staging/export helpers (`vfx_stage.luau`: refuses to stage over hand-edited templates; `vfx_export.sh`)
- receiver starter (`ensure_receiver.sh`)
- library contact sheets (`vfx_contact_sheet.py`)
- reference-video frame grids (`ref_frames.py`)
- template builders and specs (`vfx_blocks.luau`, `vfx_specs/`)
- structural template diff (`vfx_diff.luau`)
- world-event kit builder and preview (`worldfx_build.luau`, `worldfx_preview.luau`)
- seated-aura and root-reveal preview (`aura_preview.luau`)
- ambient sound template builder (`ambient_sounds_build.luau`)
- docs lint (`docs_lint.py`: broken links, missing paths, over-budget agents/skills/docs, text duplicated across agents and skills)
- duplicate finder
- POI tour and labels (`poi_tour.luau`, Studio copy `ServerStorage._EditorTools.PoiTour`)
