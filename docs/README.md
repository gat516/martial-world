# Martial World: code map

A Roblox cultivation / martial-arts game, synced with Rojo (`default.project.json`).
**Start with [the core loop](core-loop.md)**: cultivate until you hit a wall, go
out and break it, come home stronger. Every system plugs into it.
This page says where everything lives. Each system has a short design doc in
[`systems/`](systems/) (purpose, design intent, files, data flow, tuning knobs, gaps).

## Layout

| On disk | In the game | What |
|---|---|---|
| `src/shared/` | `ReplicatedStorage.Shared` | data and rules both sides use (defs, tuning, placement, action rules) |
| `src/server/` | `ServerScriptService.Server` | authority: data, cultivation, combat, enemies, garden, build, events |
| `src/client/` | `StarterPlayerScripts.Client` | input, prediction, HUD, effects |
| `assets/*.rbxmx` | mapped instances | MCP-authored Studio instances (GUIs, remotes, templates, the map) |
| `art/` | - | Blender sources and UI art scripts (not synced); the map's landforms come from `art/main_peak/` (`build_main_peak.py`, `place_main_peak.luau`) and the spirit-peak pillar scripts (`art/build_peak_pillar.py`, `art/place_peak_pillar.luau`) |
| `tools/` | - | `check.sh` (luau-lsp), rbxmx export/receive, rbxm export (keeps attributes, for VFX), VFX library search + index (`vfx_library.luau`, `vfx_library.json`), animation marker reader (`anim_markers.luau`), vfxia add-on unpacker (`vfx_addons.py`), VFX session bootstrap (`vfx_session.luau`, generated by `build_vfx_session.py`: one paste installs every Edit-mode VFX helper), add-on cheat-sheet (`vfx_addons.md`, from `vfx_addons.py --summary`), VFX preview kit (`vfx_preview.luau`: clean scene, real CombatEffects call path, frozen captures, one-call capture sweep), staging/export helpers (`vfx_stage.luau`, `vfx_export.sh`), library contact sheets (`vfx_contact_sheet.py`), template builders and specs (`vfx_blocks.luau`, `vfx_specs/`), structural template diff (`vfx_diff.luau`), duplicate finder, POI tour and labels (`poi_tour.luau`, Studio copy `ServerStorage._EditorTools.PoiTour`) |

Entry points: `src/server/Main.server.luau` (requires every server module, loads
profiles, wires remotes and hooks) and `src/client/Main.client.luau` (inits every
client module against `StarterGui.Hud`).

Mapped assets: `Remotes`, `Animations`, `Ambience`, `Effects` (binary
`assets/Effects.rbxm`, VFX templates with plugin attributes), `BuildKit`, `GardenKit`
(ReplicatedStorage); `HerbMorsel` (ReplicatedStorage, temporary eating prop);
`Hud`, `Rewards`, `Prompts` (StarterGui); `Music`, `SFX`
(SoundService); `Wilds`, `Hub` (Workspace); `Enemies`, `PeakTiers`,
`ItemTemplates`, `AmbientFX` (binary `assets/AmbientFX.rbxm`, world-ambience
effect templates: fireflies, lamp glows, mist, waterfall spray, petals; see
[world](systems/world.md)), `WeaponModels` (binary `assets/WeaponModels.rbxm`, weapon
models: one Model per class weapon joined to the Right Arm by its `Hilt`/`HiltR` Motor6D, plus
Dizi, Zither, SpiritStone and the ManualScroll prop; built by `art/weapons/place_weapons.luau`)
(ServerStorage). Never restructure these by hand in Studio: see
AGENTS.md, "Studio instances". `Workspace.Map` (peaks, plaza, cliffs, bridges,
ground, `Map.Sect.Ambience` lights) is place-only, not Rojo-mapped: see
[map](systems/map.md).

Editor-only markers: planning blockouts, POI labels and any other inspection aid go
under `Workspace._EditorMarkers` (place-only) or carry the `EditorOnly` tag. They show
in Studio Edit mode only; `src/server/EditorOnly.server.luau` destroys them when the
game runs, before anyone joins. Never leave labels or blockouts anywhere else. Every
POI, cache, find, qi node, lair, boss ring, array and event ground is tagged `POI`
(attributes `PoiName`, `Kind`, `Zone`, optional `LabelNote`); see
[map](systems/map.md), "Editor-only markers and the POI tour".

## Remotes (`ReplicatedStorage.Remotes`, `assets/Remotes.rbxmx`)

Wired in `Main.server.luau` unless noted. RemoteFunctions return `(ok, message|payload)`
and are wrapped in `guarded` (a pcall that logs and returns "Something went wrong").

| Remote | Kind | Direction | Server handler | Client user |
|---|---|---|---|---|
| CultivationAction | Function | C->S | `Circulation.handle` ("start", "finish", "cancel", "breakthrough", "method" id, "root" keepNew, "practiceStart/Finish/Cancel") | CirculationMinigame, BreakthroughView |
| Meditate | Event | both | `Meditation.handle(on)`; server fires `false` to stand you up | Meditation |
| Sprint | Event | C->S | `Cultivation.setRunning` | Sprint |
| Attack | Event | C->S | `Combat.action` (ordered begin/hit/cancel/sync) | CombatController |
| Effect | Event | S->C | many: "root" (to all: player, element, grade, first), "perfect", "damage", "hurt", "cast", "qi", "stones", "loot", "insight", "manual", "weapon", "method", "boss", "used", "bolt", "tribulationStart/End" | CombatController, CombatEffects, Rewards, RootFX |
| Telegraph | Event | S->C | `EnemyService` (attack areas before they land) | Telegraphs |
| PlayerState | Event | S->C | `Cultivation.pushState` (full snapshot) | State (everything reads State) |
| Breakthrough | Event | S->all | `Cultivation.advance` (player, stage name, major) | BreakthroughView |
| Notify | Event | S->C | toasts from everywhere | Hud |
| QuestState | Event | S->C | `Quests` (beat, objective, goals, openBoard) | Onboarding |
| BuildAction | Function | C->S | `Build.handle` ("buy", "place", "store", "move") | BuildMode, BuildCatalog |
| GardenAction | Function | C->S | `Garden.handle` ("plant", "harvest", "growTarget", "uproot", "buySeed", "sell", "sellAll") | Planting, GardenView, HerbShop |
| InventoryAction | Function | C->S | `Inventory.handle` ("use", "slot", "clear", "swap", "comprehend") | Inventory, HotbarView |
| TravelAction | Function | C->S | `Travel.go` (gate id; sect arrays from anywhere in the sect, otherwise from an array; wilds arrays only from the Sect Gate's or a wilds array) | TravelMenu |
| SaveSettings | Event | C->S | `Settings.save` | Settings |
| AdminAction | Function | C->S | `Admin.handle` (admins only) | AdminPanel |
| WeaponAction | Function | C->S | `Weapons.handle` ("equip", weaponId / "unequip" / "stow", character, boolean) | Inventory (Weapons tab), WeaponAnimator (cosmetic control locks) |
| Dodge, Cast | Event | - | unused (combat moved onto Attack) | - |

`Effect "cast"` is relayed by `Combat.releaseTechnique` to every client except the
caster as `(caster, id, origin, dir, level, chain)`; `level` is the caster's
technique level at cast time (picks the visual tier), `chain` the chain targets or nil.
`Effect "herbEat"` broadcasts `(character, itemId, serverTime)` from
`Inventory.use` to `HerbAnimator` on every client after a successful herb use.

Besides remotes, the server publishes fast-changing values as attributes:
player `Realm`, `Cultivation`, `CultivationMax`, `RawQi`, `DantianCap`, `Stones`, `Root`, `RootGrade`, `Method`, `Meditating` (seated; for others' method auras),
`DeviationUntil`, `Admin`, `Peak`/`PeakFrame`, `Weapon`; character `WeaponClass`, `WeaponStowed`
(combines Tool occupancy, `WeaponControlsLocked`, `WeaponBreakthroughUntil`); humanoid `BaseWalkSpeed`,
`Running`, `ActionBusy`; enemy `AIState`, `Realm`; workspace `Weather`,
`WeatherEnds`, `WorldEvents`; plot `Plants` (JSON).

## Server hook pattern

Modules expose hook lists that `Main.server.luau` fills, which keeps modules from
requiring each other in circles: `Cultivation.onBreakthrough`, `.onPush`,
`.onInsightBlocked`; `EnemyService.onKill`; `Circulation.onFinished`;
`Tribulation.onFinished`; `Quests.onBeat`; `Progression.onEarned`. Some are
function slots set by the module that owns the answer: `Cultivation.meditation`
(Meditation), `Cultivation.inCombat` (Combat), `Cultivation.startTribulation`
(Tribulation), `Progression.slotTechnique` (Inventory).

## Where to look when...

- **A number feels wrong in progression**: `Pacing.luau` first; it says which knob does what.
- **A HUD value is stale**: is it an attribute (`Cultivation.publish`) or in the `PlayerState` push? See [ui](systems/ui.md).
- **`attempt to index nil` on a GUI/asset child**: probably a duplicate or a missing MCP-authored instance; see AGENTS.md.
- **A remote call fails silently**: the server's `guarded` wrapper logs `Remote error for <name>` in the output.
- **Inspecting a POI or cache in Studio**: `local T = require(game.ServerStorage._EditorTools.PoiTour)`, then `T()` lists them, `T(12)` or `T("WolfDen")` frames one from a player's eye height, `T.labels()` rebuilds the floating labels.
- **Saved data**: `PlayerData.luau` (`Data` type, `default()`, `migrations`).
